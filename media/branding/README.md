# AjarOS artwork

This folder holds the masters of the AjarOS artwork and the scripts that turn them into the bitmaps and icons the
system builds. Only `wallpaper/AjarOS.bmp` is built from here (see `CMakeLists.txt`); every other output replaces
a file elsewhere in the tree, in the format of the file it replaces.

## Concept

"Ajar" is a window left slightly open. The mark is a window frame whose right casement is swung a little
outwards on its hinge: the near edge of the casement stands taller than the frame, and warm light shows through
the gap. It is meant to read as open, calm and trustworthy, with a little warmth. The wordmark sets "Ajar" in a
semibold and "OS" in a regular weight; the dot of the j is a small lamp-coloured pane.

## Palette

`src/palette.css` is the one definition of the colours. The SVG masters use its classes (`f-` fill, `s-` stroke,
`c-` gradient stop) and `tools/render.py` reads the hex values from it.

| Name | Hex | Use |
|---|---|---|
| deep | `#0B4F6C` | primary: frame, wordmark "Ajar", dark banners |
| ink | `#0A2E3D` | darkest tone: sash edge, banner shadows |
| harbor | `#2D7FA6` | secondary blue-teal: wordmark "OS", turned glass |
| sky | `#8FCDE3` | glass, "OS" on dark grounds |
| mist | `#DDF0F6` | light glass, light grounds |
| lamp | `#F2A93B` | the warm accent: the light in the gap, the j dot |
| glow | `#FFD889` | light accent: the brightest part of the light |
| cloud | `#F5F8FA` | light background |
| slate | `#5A6E78` | secondary text |
| white | `#FFFFFF` | text and frame on dark grounds |

The default desktop colour stays RGB 58, 110, 165; the palette sits next to it, and the wallpaper starts from it.

The boot screen has 16 colours, taken from `logo.bmp`. Its palette (in `render.py`, `BOOT`) keeps the brightness
order of the indices that the kept boot bitmaps use for antialiasing (copyright, shutdown and hibernate text) and
puts the brand colours in place of the old blue-greys: 4 lamp, 5 deep, 7 harbor, 10 sky, 11 glow, 13 mist.
Index 15 stays white because the kernel fills the progress bar with it. The text-mode (SOS) header carries its own
16-colour palette, which becomes the screen palette: background index 7 (workstation) or 6 (server), text 15 or
14, footer band 1.

## Masters (`src/`)

| File | What |
|---|---|
| `mark.svg` | the mark, 64-unit grid; used from 40 px up |
| `mark-16/20/24/32.svg` | the mark fitted to each pixel grid (generated by `tools/marksizes.py`) |
| `mark-reverse.svg`, `mark-reverse-NN.svg` | the mark for dark grounds: light frame, darker glass |
| `mark-glyph-16/20/24.svg` | one-colour mark for the themed Start buttons |
| `mark-flat.svg` | flat mark without gradients for the 16-colour boot screen; edges on the grid at 64 and 128 px |
| `wordmark.svg`, `wordmark-reverse.svg` | the wordmark for light and dark grounds (generated by `tools/wordmark.py`) |

## Outputs and their formats

Formats are read from the upstream originals (`--orig`, default the branch's upstream base), and
`tools/checkformats.py TREE` checks that size, bit depth, compression, palette size and pixel data size still match.

## Rebuilding

Run on a machine with `rsvg-convert`, Pillow, numpy and fontTools:

    python3 media/branding/tools/marksizes.py media/branding/src
    python3 media/branding/tools/wordmark.py media/branding/src
    python3 media/branding/tools/render.py . --sheet /some/dir
    python3 media/branding/tools/checkformats.py .

Resource files do not track the bitmaps they embed: after changing artwork, build from a fresh build directory or
delete the affected `.res` objects.
