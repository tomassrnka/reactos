# Argument types of the system call prototypes, for wow64protos.
# One type per line: name, kind, size on i386 in bytes, size on amd64 in bytes.
#   int      integer or enumeration, same size on both architectures
#   ptrint   pointer-sized integer
#   handle   pointer-sized handle
#   pointer  pointer or function pointer (a pointer typedef; a star is recognised without an entry)
#   struct   structure or union passed by value
#   float    floating point
# Multi-word C types join their words with an underscore (unsigned_long). An argument whose
# type is missing here is reported as unresolved and is not part of a slot-count check.
# Every size below was checked with a static assertion per type, compiled for i386 and for
# amd64 against the win32k and NDK headers (the one exception is noted on its line).
